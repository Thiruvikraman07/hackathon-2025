# Test Company Repository

This is a test repository for a fictional company that builds web applications using modern technologies.

## Overview

Our company specializes in building scalable web applications using Python, FastAPI, and React. We focus on creating high-performance APIs and interactive user interfaces.

## Tech Stack

- **Backend**: Python 3.11+, FastAPI, PostgreSQL
- **Frontend**: React, TypeScript, Tailwind CSS
- **Infrastructure**: Docker, AWS, GitHub Actions
- **Testing**: pytest, Jest, Cypress

## Project Structure

```
src/
  api/          - REST API endpoints
  models/       - Database models
  services/     - Business logic
  utils/        - Helper functions
tests/          - Test suites
```

## Getting Started

1. Install dependencies: `pip install -r requirements.txt`
2. Run the server: `uvicorn src.main:app --reload`
3. Access API docs: `http://localhost:8000/docs`
